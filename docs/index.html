What the desk does

Windows. You open a folder. The list and the stack are the same folder. The stack is sorted by size as the sizes come in.

A STACK BY SIZE The largest item sits at the front. Arrow keys walk the stack. The callout names the one you are on.
A PREVIEW Space opens a file, or the contents of a folder, and you stay where you were. Escape closes it.
FIND Ctrl+F searches this folder. Tab switches to every subfolder under it.
A VOLUME RAIL Volumes, the desktop, and pins. Press T, or drag a row onto a volume, to copy.
A TERMINAL Ctrl+J opens a terminal in the folder you are looking at. A bare cd follows the folder.
DARK MODE The same type as the app. Bahnschrift for the interface. Cascadia Mono for the codes.

Run it

Node.js on Windows. The dev command starts the window. The page inside it is served at http://localhost:3123.

npm install
npm run dev
